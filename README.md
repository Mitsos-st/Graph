Μια ελαφριά, web-based εφαρμογή για τη σχεδίαση μαθηματικών συναρτήσεων και την οπτικοποίηση δεδομένων στο καρτεσιανό επίπεδο. Το project εστιάζει στην ταχύτητα και την ευκολία χρήσης απευθείας από τον browser.

### Χαρακτηριστικά
Σχεδίαση Συναρτήσεων: Εισαγωγή μαθηματικών τύπων και άμεση απεικόνιση στο γράφημα.

Διαδραστικό Canvas: Δυνατότητα πλοήγησης στο σύστημα συντεταγμένων.

Vanilla Stack: Κατασκευασμένο αποκλειστικά με standard web τεχνολογίες για μηδενικό χρόνο φόρτωσης.

Responsive Design: Προσαρμόζεται σε διαφορετικά μεγέθη οθόνης.
